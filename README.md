
System obsługi konsultacji wykładowców (Rezerw+WSPA)
System umożliwia studentom rezerwację terminów konsultacji u wykładowców, a wykładowcom
zarządzanie harmonogramem konsultacji i listą zapisanych osób. Zastępuje chaotyczną
korespondencję mailową jednolitą platformą internetową.

## Umowa zespołu

- Nikt nie zapisuje bezpośrednio do `main`. Zmiany przez gałąź i pull request.
- Każdy PR ma co najmniej 1 zatwierdzenie drugiej osoby.
- Nazwy gałęzi: `obszar/krotki-opis`, małe litery, bez polskich znaków.
- Każde zadanie to Issue z jednym właścicielem. Zamykamy przez `Closes #n`.
